## 논의할 내용

### 1. 모임 일정과 방식

- 정해진 사항: 주 1회 퇴근 후 모입니다.
- 무슨 요일과 시간에 모일까요?
- 온라인과 오프라인 중 어떤 방식으로 진행할까요?
- 참석이 어렵거나 일정 변경이 필요할 때 어떻게 공유할까요?

### 2. 주제와 프로젝트 범위

- 정해진 사항: 같은 주제를 각자 구현해 모임에서 발표합니다.

- 주제는 어떻게 제안하고 선택할까요?
- 하나의 주제에 얼마 동안 도전할까요?
- 모두에게 공통으로 요구할 기능과 각자 자유롭게 정할 부분은 무엇일까요?
- 완성하지 못했을 때는 어떻게 진행할까요?

### 3. 기술과 개발 환경

- 정해진 사항: 모든 프로젝트에 Python을 사용하고, 버전은 3.13으로 통일합니다.
- 프레임워크와 라이브러리는 각자 자유롭게 선택할까요?

### 4. AI와 참고 자료

- 정해진 사항: 코드 작성과 문제 해결에 AI 도움 없이 직접 진행합니다.
- 공식 문서, 검색, 예제 코드 등은 어떻게 활용할까요?
- 참고한 자료는 어떻게 기록하고 공유할까요?

### 5. 레포지토리와 작업 공유

- 정해진 사항: 주제별 레포지토리 하나를 만들고 각자 폴더에 구현물을 올립니다.
- 정해진 이름 규칙: `01-주제`, `02-주제`처럼 순번과 주제를 함께 적습니다.
- 정해진 문서화 방식: 각자 폴더의 README에 프로젝트를 설명하고, `docs/`에 트러블슈팅을 기록합니다.
- 정해진 트러블슈팅 파일명: `YYYY-MM-DD-문제-요약.md` 형식으로, 기록한 날짜와 영문 소문자·하이픈으로 된 문제 요약을 사용합니다.

- 개인 폴더의 세부 구성은 어떻게 할까요?
- 브랜치와 PR을 사용할까요? 사용한다면 언제 올릴까요?
- 실행 방법과 의존성은 어디에 기록할까요?

### 6. 발표와 피드백

- 각자 어떤 내용과 분량으로 발표할까요?
- 결과물 시연, 코드 설명, 어려웠던 점 중 무엇을 공유할까요?
- 피드백은 어떤 방식으로 주고받을까요?

### 7. 첫 프로젝트 후보: 미래 자산 계산기

> 제안 단계이며 주제와 범위는 함께 결정합니다.

- 월급과 소비 계획, 예금·적금 등 저축 계획을 입력해 미래 자산을 예상하는 터미널 프로그램은 어떨까요?
- 수입·소비·저축 계획의 추가·조회·수정·삭제와 월 잔액 계산을 공통 기능으로 할까요?
- 계산 기준(실수령액, 이율, 납입 시점, 세금 등)과 예상 결과의 가정을 어떻게 정할까요?
- 금융상품 정보는 직접 입력하고, 공개 데이터 연동은 선택 기능으로 둘까요?
- 예상 기간 2주와 `01-future-asset-calculator` 레포 이름을 사용할까요?
