# 그라운드 룰 회의 템플릿

회의할 때 이 문서를 복사해 `YYYY-MM-DD-ground-rules.md`로 저장하고 내용을 채웁니다. 날짜는 실제 회의한 날을 사용합니다.

- **날짜:** 미정
- **참석자:** 미정
- **목적:** 스터디를 꾸준히 진행하기 위한 기본 약속을 함께 정합니다.

## 논의할 내용

### 1. 모임 일정과 방식

- 얼마나 자주, 무슨 요일과 시간에 모일까요?
- 온라인과 오프라인 중 어떤 방식으로 진행할까요?
- 참석이 어렵거나 일정 변경이 필요할 때 어떻게 공유할까요?

### 2. 주제와 프로젝트 범위

- 주제는 어떻게 제안하고 선택할까요?
- 하나의 주제에 얼마 동안 도전할까요?
- 모두에게 공통으로 요구할 기능과 각자 자유롭게 정할 부분은 무엇일까요?
- 완성하지 못했을 때는 어떻게 진행할까요?

### 3. 기술과 개발 환경

- 프로젝트에서 Python을 어느 범위까지 사용할까요?
- 정해진 사항: Python 3.13으로 통일합니다.
- 프레임워크와 라이브러리는 각자 자유롭게 선택할까요?

### 4. AI와 참고 자료

- 정해진 사항: 코드 작성과 문제 해결에 AI 도움 없이 직접 진행합니다.
- 공식 문서, 검색, 예제 코드 등은 어떻게 활용할까요?
- 참고한 자료는 어떻게 기록하고 공유할까요?

### 5. 레포지토리와 작업 공유

- 정해진 이름 규칙: `01-주제`, `02-주제`처럼 순번과 주제를 함께 적습니다.

- 주제별 레포지토리와 개인 폴더는 어떻게 구성할까요?
- 브랜치와 PR을 사용할까요? 사용한다면 언제 올릴까요?
- 실행 방법과 의존성은 어디에 기록할까요?

### 6. 발표와 피드백

- 각자 어떤 내용과 분량으로 발표할까요?
- 결과물 시연, 코드 설명, 어려웠던 점 중 무엇을 공유할까요?
- 피드백은 어떤 방식으로 주고받을까요?
