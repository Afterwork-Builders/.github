# Afterwork Builders

퇴근 후 함께 모여, 직접 코드를 작성하며 아이디어를 실제 프로젝트로 만들어가는 스터디입니다.

## 우리가 추구하는 것

- 작은 기능부터 시작해 동작하는 결과물을 완성합니다.
- 코드를 작성하고 문제를 해결하는 과정을 통해 배웁니다.
- 각자 만든 프로젝트와 시행착오를 공유하고 서로 피드백합니다.

## 스터디 방식

- **시간:** 주 1회 퇴근 후 진행합니다. 구체적인 요일과 시간은 함께 정합니다.
- **프로젝트:** 각자 만들고 싶은 주제를 정해 개발하고 조직의 레포지토리에 공유합니다.
- **기술:** 모든 프로젝트에 Python을 사용합니다. 필요한 다른 언어와 도구는 자유롭게 선택합니다.
- **Python 버전:** Python 3.13으로 통일합니다.
- **AI 사용:** 코드를 작성하거나 문제를 해결할 때 AI의 도움을 받지 않습니다. 공식 문서와 검색, 서로의 피드백을 활용합니다.

## 진행 흐름

1. 각자 만들고 싶은 프로젝트와 작은 목표를 정합니다.
2. 직접 구현하고, 코드와 실행 방법을 레포지토리에 정리합니다.
3. 모임에서 진행 상황과 어려웠던 점을 공유합니다.
4. 서로의 코드를 살펴보고 의견을 나누며 다음 목표를 정합니다.

완벽하게 시작하기보다, 작은 것을 꾸준히 만들어갑니다.
