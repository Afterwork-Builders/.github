# Afterwork Builders

퇴근 후 함께 모여, 직접 코드를 작성하며 아이디어를 실제 프로젝트로 만들어가는 스터디입니다.

같은 주제를 각자의 방식으로 구현하고, 결과물과 고민을 나누며 함께 성장합니다.

## 스터디 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| **모임** | 주 1회 퇴근 후 진행합니다. 요일과 시간은 함께 정합니다. |
| **주제** | 함께 하나의 주제와 목표를 정하고, 각자 직접 구현합니다. |
| **기술** | 모든 프로젝트에 Python을 사용합니다. 다른 언어와 도구도 자유롭게 사용할 수 있습니다. |
| **Python 버전** | Python 3.13으로 통일합니다. |
| **AI 사용** | 코드 작성과 문제 해결에 AI의 도움을 받지 않습니다. 공식 문서, 검색과 서로의 피드백을 활용합니다. |
| **발표** | 각자 만든 결과물과 구현 과정, 어려웠던 점을 공유합니다. |

## 진행 방식

1. **주제 선정** — 함께 만들 주제와 목표를 정합니다.
2. **각자 구현** — 같은 주제를 각자의 방식으로 만들고, 코드와 실행 방법을 정리합니다.
3. **발표와 피드백** — 결과물을 소개하고 서로의 접근 방식과 코드를 살펴봅니다.
4. **다음 주제 선정** — 배운 내용을 나누고 다음에 만들 것을 정합니다.

## 레포지토리 구성

주제마다 조직에 레포지토리를 하나 만들고, 각자의 폴더에 구현물을 올립니다.

```text
주제별-레포지토리/
├── README.md        # 공통 주제와 목표
├── member-a/        # 각자의 구현물과 실행 방법
├── member-b/
└── member-c/
```

작은 것부터 시작해 꾸준히 만들어갑니다.
